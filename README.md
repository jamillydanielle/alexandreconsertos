# Alexandre — Central de links

Página de links do Alexandre Conserto de Geladeiras e Máquinas, em Lavras/MG.

## Recursos

- Acesso à avaliação da Loja 1 no Google.
- Localização das lojas.
- Página no Facebook.
- Layout responsivo com a identidade visual do negócio.

## Estrutura

`index.html` reúne a página e os estilos. O projeto usa HTML e CSS, sem dependências.

## Desenvolvimento

Abra `index.html` no navegador para visualizar. Edite o arquivo para atualizar textos, estilos e links.

## Publicação

Para publicar no GitHub Pages, configure a branch `main` e a pasta raiz em Settings → Pages. Cada atualização na branch será publicada automaticamente após a ativação.
